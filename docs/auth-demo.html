Вход через OpenMarket

Один аккаунт для сайтов и приложений сообщества: проверка идёт по реестру пользователей магазина.

Это упрощённая схема: реестр users.txt хранится в публичном репозитории, поэтому хеши паролей технически доступны всем. Не используйте здесь пароль, который вы применяете в других сервисах. Для боевых проектов нужен полноценный OAuth-провайдер. 

<script src="openmarket-auth.js"></script>
<script>
  OpenMarketAuth.signIn('user@example.com', 'пароль')
    .then(function (session) {
      console.log('Вошел:', session.email, 'роль:', session.role);
    })
    .catch(function (error) {
      console.error(error.code); // user_not_found | wrong_password | registry_unavailable
    });
</script>
