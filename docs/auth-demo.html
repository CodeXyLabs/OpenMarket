Вход через OpenMarket

Один аккаунт магазина для сайтов, приложений и игр. Подключение — две строки кода.

Живая кнопка

Это настоящий виджет: он проверяет аккаунт по реестру OpenMarket и запоминает вход в браузере.

Подключение на сайте

<div id="om-auth"></div>
<script src="https://codexylabs.github.io/OpenMarket/openmarket-auth.js"></script>
<script>
  OpenMarketAuth.mount('#om-auth', {
    onSignIn: function (user) {
      console.log('Вошёл:', user.email, 'роль:', user.role);
    }
  });
</script>

Без виджета (свой интерфейс)

OpenMarketAuth.signIn(email, password)
  .then(function (user) { /* user.email, user.role */ })
  .catch(function (error) { /* error.code */ });

OpenMarketAuth.currentUser();   // сессия из localStorage или null
OpenMarketAuth.signOut();
OpenMarketAuth.on('change', function (user) { /* вход/выход */ });

В Android-приложении или игре

Возьмите готовый файл OpenMarketAuth.android.kt — это один класс без зависимостей: OpenMarketAuth.signIn(email, password) { user, error -> }.

Схема упрощённая: реестр users.txt лежит в публичном репозитории, поэтому хеши паролей технически видны всем. Не используйте здесь пароль от других сервисов; для боевого проекта понадобится полноценный OAuth-провайдер.
